# Інструкція з експлуатації системи DigiUni Registry

DigiUni Registry - це багатофункціональна інформаційна система, призначена для комплексного обліку академічних ресурсів університету (НаУКМА). Проєкт реалізує клієнт-серверну архітектуру та надає інструменти для управління даними студентів, викладачів та організаційної структури ВНЗ.

## 1. Архітектура та мережевий режим
* **Клієнт-серверна взаємодія:** Система розділена на серверну частину, що зберігає базу даних, та клієнтську частину для віддаленого доступу через TCP-сокети.

## 2. Управління даними (CRUD)
Система дозволяє виконувати повний цикл операцій з основними сутностями:
* **Студенти:** додавання, пошук за ID, оновлення даних, відрахування та переведення на наступний курс.
* **Викладачі:** ведення особистих карток, облік посад, наукових ступенів та прив'язка до кафедр.
* **Організаційна структура:** управління реєстрами факультетів, кафедр та спеціальностей.

## 3. Система пошуку та фільтрації
* **Гнучкий пошук:** пошук людей за ПІБ (повний або частковий збіг), курсом, групою або кафедрою.
* **Сортування:** впорядкування списків за алфавітом або датою додавання з використанням Stream API.
* **Валідація:** автоматична перевірка коректності введених даних (обов'язкові поля, вікові обмеження) через рефлексію та анотації.

## 4. Модуль аналітики та статистики
Система генерує детальні звіти на основі актуальних даних:
* **Факультети:** загальна кількість, середня кількість студентів і кафедр на факультет, рейтинги популярності.
* **Спеціальності:** аналіз затребуваності, розподіл студентів за формами навчання (бюджет/контракт).
* **Студенти:** розподіл за курсами (з візуальною гістограмою), гендерна статистика та перевірка "різноманітності" (унікальність прізвищ).
* **Викладачі:** статистика за посадами та гендерний баланс у колективі.
* **Загальні показники:** розрахунок співвідношення кількості студентів до викладачів (Student-to-Teacher ratio).

## 5. Графічний інтерфейс (Visual Cards)
Для зручності візуалізації даних реалізовані інтерактивні картки на JavaFX:
* **Динамічні фото:** автоматичне завантаження особистих фото за ID або встановлення аватара на основі визначення статі за ім'ям.
* **Статусні маркери:** візуальні "штампи" на картках (наприклад, мітки "Бюджет", "Контракт" або "Архів" для відрахованих студентів).
* **Контактний блок:** швидкий перегляд email та номерів телефонів співробітників і студентів.

## 6. Безпека та зберігання даних
* **Рольова модель (RBAC):** розмежування прав доступу для рівнів "Адміністратор" (повний доступ), "Менеджер" (редагування) та "Користувач" (тільки перегляд і статистика).
* **Зберігання в CSV:** всі дані зберігаються у структурованих файлах, що дозволяє відновлювати стан системи після перезапуску.
* **Логування:** фіксація всіх критичних дій та помилок у файл registry.log для аудиту безпеки.
